Política de Privacidade — GP Premium CRM

Última atualização: 2 de julho de 2026

A extensão GP Premium CRM é uma ferramenta interna de atendimento e agendamentos utilizada exclusivamente pela equipe da GP Premium sobre o WhatsApp Web.

1. Quais dados a extensão trata

  • Credenciais de acesso ao CRM (e-mail e senha do atendente) — usadas apenas para autenticar o atendente no sistema interno.
  • Contatos e mensagens do WhatsApp do atendente — sincronizados com o servidor privado da empresa para viabilizar agendamentos e histórico de atendimento.

2. Para onde os dados vão

Os dados são enviados exclusivamente para o servidor privado da própria empresa (crm.nailacademyprofissional.com), por conexão criptografada (HTTPS). Nenhum dado é enviado a terceiros, vendido, compartilhado ou usado para publicidade.

3. O que a extensão NÃO faz

  • Não coleta histórico de navegação;
  • Não acessa outros sites além do WhatsApp Web e do servidor do CRM;
  • Não utiliza os dados para fins de rastreamento, análise de comportamento ou publicidade;
  • Não repassa dados a terceiros.

4. Armazenamento e retenção

Os dados ficam armazenados no banco de dados privado da empresa e são mantidos apenas enquanto necessários para a operação do atendimento. O atendente pode solicitar a exclusão dos seus dados a qualquer momento.
